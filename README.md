# Python Data Structures

A collection of Python examples for understanding data structures, their operations, and their use in programming.

## Learning objectives

- Understand how data structures store and organise information.
- Explore common operations and their behaviour.
- Practise Python implementation and problem-solving.
- Build a foundation for algorithms and technical interviews.

## Prerequisites

- Python 3.
- Git.

## Installation

```bash
git clone https://github.com/MehtaVishesh/python-data-structures.git
cd python-data-structures
```

## Run an example

Run a Python file from the repository:

```bash
python path/to/example.py
```

Replace the example path with the location of an existing Python file.

## How to explore the repository

Read each implementation, test its operations with different inputs, and trace how each operation changes the stored data.
